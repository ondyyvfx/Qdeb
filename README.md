# QDeb 🗣️

QDeb — это веб-платформа для проведения и организации дебатных мероприятий. Здесь участники могут находить клубы, регистрироваться на турниры и улучшать свои навыки публичных выступлений.

## 🚀 Функциональность

- Поиск и просмотр дебатных клубов
- Регистрация пользователей и вход
- Профиль участника с аватаркой и описанием
- Секции лучших спикеров и мероприятий
- Адаптивный интерфейс с современной версткой

## 🛠️ Технологии

- **Next.js** + **TypeScript**
- **Tailwind CSS** + **shadcn/ui**
- **Zustand** / **Context API** для управления состоянием
- Подключение к backend (в разработке)

## 📁 Установка

```bash
git clone https://github.com/ondyyvfx/qdeb.git
cd qdeb
npm install
npm run dev
```
