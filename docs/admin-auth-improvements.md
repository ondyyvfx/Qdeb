# Улучшения системы проверки прав администратора

## Проблема

Ранее при попытке не-админа зайти на страницу создания турниров происходили краши из-за неправильной обработки состояний авторизации и отсутствия понятных сообщений для пользователя.

## Решение

### 1. Созданы утилиты для проверки прав (`lib/auth-utils.ts`)

- `isAdmin(user)` - проверка, является ли пользователь администратором
- `isAuthenticated(user)` - проверка авторизации
- `hasRole(user, role)` - проверка конкретной роли
- `formatUserRoles(user)` - форматирование ролей пользователя

### 2. Созданы переиспользуемые компоненты

- `LoadingState` - состояние загрузки
- `LoginRequiredMessage` - сообщение о необходимости авторизации
- `AccessDeniedMessage` - сообщение об отсутствии прав
- `AdminOnlyPage` - обертка для страниц администратора

### 3. Создан хук `useAdminAuth`

- Централизованная логика проверки прав администратора
- Обработка всех состояний: проверка, авторизован, неавторизован, нет прав
- Автоматическое перенаправление при отсутствии токена

### 4. Улучшена страница создания турниров

- Использует новые компоненты и хуки
- Понятные сообщения об ошибках
- Красивые UI состояния для каждого случая
- Отсутствие крашей при неправильных правах

### 5. Улучшена страница турниров

- Использует утилиты для проверки прав
- Показывает подсказку "Только для администраторов" вместо скрытия кнопки

## Преимущества

- ✅ Нет крашей при неправильных правах
- ✅ Понятные сообщения для пользователя
- ✅ Переиспользуемые компоненты
- ✅ Централизованная логика проверки прав
- ✅ Красивые UI состояния
- ✅ Легкость поддержки и расширения

## Использование

### Для новых страниц администратора:

```tsx
import AdminOnlyPage from "@/components/shared/AdminOnlyPage";

export default function AdminPage() {
  return (
    <AdminOnlyPage
      title="Недостаточно прав"
      message="Только администраторы могут получить доступ"
    >
      {/* Контент страницы */}
    </AdminOnlyPage>
  );
}
```

### Для проверки прав в компонентах:

```tsx
import { isAdmin } from "@/lib/auth-utils";

if (isAdmin(user)) {
  // Показать админский контент
}
```
